# CoS Prep – Owlbear Rodeo-tillägg

Placerar Curse of Strahd-monster **dolda** på rätt rutor på Beneos-kartorna och kopplar dem
direkt till rätt statblock i Game Master's Grimoire (Tabletop Almanac, 2024-versionerna).

## Installera
Owlbear Rodeo → Profile → Extensions → Manage → "Add custom extension" →
`https://anderse77.github.io/cos-owlbear-prep/manifest.json`

## Använda
1. Öppna CoS Prep i rummet (ikonen uppe till vänster).
2. **Välj monsterbilder** (en gång): markera monstrens bilder i dina assets. Bilderna ska heta exakt som monstret (t.ex. `Ghoul`).
3. Gå till rätt scen, välj plats och tryck **Placera dolda monster**.
4. Ångra med **Ta bort platsens monster**.

## Lägga till platser
Redigera `locations.js`. Positioner anges i rutor på Beneos 4K-kartan (32×18 rutor, 120 px/ruta).
